# Roadmap
1. **Add selectable EMA overlays to both candlestick charts.** Data: available — compute configurable EMA periods from each stock's daily closing prices.

2. **Show volatility by EMA trend regime.** Data: available — derive daily returns and EMA direction from the existing prices, then compare volatility when price is above or below its EMA.


3. **Add a crosshair with date and price-axis readouts.** Data: available — chart timestamps and OHLC values provide the exact labels for the candle under the pointer.

4. **Add a shared date-range selector for both stock charts and the volatility view.** Data: available — both daily price files cover 2024 and the volatility file contains monthly 2024 summaries.


5. **Add a normalized NVDA-versus-TSLA performance chart.** Data: available — both price files include adjusted closing prices that can be rebased to the same starting value.
